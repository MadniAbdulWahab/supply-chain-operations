# German market alignment snapshot

Research date: 2026-08-12. Job listings change; links are evidence for project-shaping only,
not a statistical labor-market analysis.

| Hiring signal | Project evidence |
|---|---|
| Strong SQL and Python | SQL transformations/assertions plus tested Python package |
| Reliable pipelines and tested datasets | Idempotent ingestion, quarantine, manifest, CI |
| Dimensional modeling | Documented star schema with declared fact grain |
| Data quality, lineage, and root-cause analysis | Rule catalog, lineage metadata, DQ fact |
| Self-service reporting | KPI contract and three Power BI page specifications |
| Fabric/Power BI consulting | Explicit local-to-Fabric mapping and verification ledger |
| Stakeholder communication | Business question, definitions, runbook, German summary |
